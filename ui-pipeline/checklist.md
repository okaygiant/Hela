# Чек-лист самопроверки UI

Для каждого пункта: ок / не ок / нет данных. «Ок» только после реальной проверки.

## Токены и система
- [ ] Линтер: 0 нарушений
- [ ] Нет значений вне `tokens.css`
- [ ] Использованы только существующие компоненты
- [ ] Один акцентный цвет/кнопка на экран

## Раскладка
- [ ] Все отступы кратны 4px и взяты из шкалы
- [ ] Боковые поля = `--screen-gutter`, одинаковые на всех блоках
- [ ] Нет горизонтального скролла на 375px
- [ ] Ничего не обрезается на 430px и 1280px

## Типографика
- [ ] Не больше 3–4 размеров шрифта на экране
- [ ] Чёткая иерархия: заголовок → основное → вторичное
- [ ] Числа (деньги, ставки) в одном формате, выровнены

## Интерактив
- [ ] Все тапабельные элементы ≥ `--tap-min` (44px)
- [ ] Есть hover/pressed/focus/disabled
- [ ] Главное действие достижимо большим пальцем (мобайл)

## Состояния и данные
- [ ] Loading, empty, error показаны
- [ ] Длинные значения (имя, сумма, валюта) не ломают вёрстку
- [ ] Нулевые и отрицательные значения выглядят корректно

## Доступность
- [ ] Контраст текста ≥ 4.5:1 (основной), ≥ 3:1 (крупный/иконки)
- [ ] Статус не передаётся только цветом
- [ ] Видимый focus-стиль

## Сверка с референсом
- [ ] Список расхождений с референсом приложен
- [ ] Каждое расхождение либо исправлено, либо объяснено

## Telegram WebView
- [ ] Нет жёстких 390 / 844 / 984 / 100vh в коде экрана (кроме страниц-симуляторов)
- [ ] Ширины 360, 390, 430: ничего не обрезается, поля `--screen-gutter` на месте
- [ ] Верх и низ учитывают safe area (в том числе полноэкранный режим)
- [ ] Плавающий таббар и CTA не залезают под Home Indicator
- [ ] Нет зависимости от hover
